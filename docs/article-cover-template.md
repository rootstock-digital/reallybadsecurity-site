# RBS article-cover template

Use the shared `public/media/security-signals/article-cover-template.png` background for Security Signals preview cards.

- Canvas: 1280 × 720 (16:9), matching the YouTube thumbnail frame.
- Background: warm notebook paper, faint grid, restrained navy and orange edge details.
- Title: one centered, all-caps title; no category, series name, date, subtitle, badge, or logo.
- Typography: bold navy sans serif; use balanced lines and keep generous space around the title.
- Website use: the preview renders the title over the shared background automatically. A Canva version should use the same canvas, background, and centered title-safe area.
